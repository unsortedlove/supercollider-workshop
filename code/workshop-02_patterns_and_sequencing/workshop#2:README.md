# Workshop 02 — Patterns and Algorithmic Sequencing

A beginner-friendly introduction to sequencing, pattern systems, and algorithmic composition using SuperCollider.

This workshop focuses on creating musical structures through code. Participants will learn how to design instruments, generate musical events, control parameters over time, and create sequences using SuperCollider's pattern system.

No previous experience with SuperCollider or programming is required.

## Learning Objectives

By the end of this workshop participants will be able to:

- Create reusable SynthDefs
- Understand the role of parameters in sound synthesis
- Generate sequences using patterns
- Work with deterministic and random processes
- Control multiple synthesis parameters over time
- Understand rhythm, duration, tempo, and quantisation
- Build simple algorithmic compositions

---

## Workshop Structure

### 01 — What Is a SynthDef?

Introduction to:

- SynthDefs
- Oscillators
- Filters
- Envelopes
- Instrument design

### 02 — Controlling Parameters

Understanding how parameters affect sound:

- Frequency
- Filter cutoff
- Amplitude
- Attack
- Release

### 03 — What Is a Pattern?

Introduction to patterns as generators of values over time.

Topics include:

- Repetition
- Sequences
- Pattern logic
- Event generation

### 04 — Pseq, Prand and Pxrand

Exploring different pattern behaviours:

- Fixed sequences
- Random sequences
- Non-repeating random sequences
- Continuous random values

### 05 — Pbind and Instruments

Connecting patterns to SynthDefs.

Topics include:

- Events
- Musical sequencing
- Instrument control
- Automatic note generation

### 06 — Controlling Multiple Parameters

Using patterns to simultaneously control:

- Pitch
- Filter frequency
- Amplitude
- Envelope characteristics
- Timing

### 07 — Duration and Rhythm

Understanding temporal structure:

- dur
- Beats
- Rhythmic organisation
- Event spacing

### 08 — Tempo and Quantisation

Synchronising musical processes:

- TempoClock
- BPM
- Beat relationships
- Quantisation
- Pattern synchronisation

### 09 — Final Exercises

Creative exercises combining all concepts introduced during the workshop.

Participants are encouraged to create:

- Calm systems
- Chaotic systems
- Machine-like systems
- Generative compositions

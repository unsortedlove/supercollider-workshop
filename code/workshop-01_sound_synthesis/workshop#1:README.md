# Workshop 01 — Sound Synthesis Fundamentals

A beginner-friendly introduction to sound synthesis using SuperCollider.

This workshop explores how sound is generated, shaped, and transformed through code. Participants will learn the fundamental concepts behind digital synthesis, including oscillators, envelopes, sound design techniques, and generative systems.

No previous experience with SuperCollider or programming is required.

## Learning Objectives

By the end of this workshop participants will be able to:

- Navigate the SuperCollider environment
- Understand the relationship between the language and audio server
- Create sounds using UGens
- Shape sounds with envelopes
- Build custom SynthDefs
- Work with scales, degrees, and chords
- Explore generative approaches to composition
- Develop basic sound design skills

---

## Workshop Structure

### 01 — Interface and Syntax

Introduction to:

- SuperCollider IDE
- Post Window
- Variables
- Messages
- Code evaluation
- Documentation

### 02 — Server and UGens

Understanding the fundamentals of SuperCollider:

- sclang
- scsynth
- Functions
- Synths
- Unit Generators (UGens)
- Audio-rate and control-rate processing

### 03 — Envelopes

Controlling sound over time:

- Line
- XLine
- Env
- EnvGen
- Gates
- ADSR envelopes
- Resource management with doneAction

### 04 — Advanced Envelopes

Creating more sophisticated control structures:

- Custom envelope shapes
- Envelope curves
- Retriggering
- Frequency envelopes
- Envelope modulation
- Multi-stage control signals

### 05 — Musical Patterns and Pitch

Introduction to musical organisation:

- Scales
- Degrees
- Chords
- Arpeggios
- Legato
- Strumming
- Musical structures

### 06 — Generative Composition

Building autonomous musical systems:

- TempoClock
- Pbindef
- Controlled randomness
- Simple generative techniques
- Emergent musical behaviour
